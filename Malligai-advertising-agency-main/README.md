# Malligai Advertising Agency

A modern advertising agency landing page built with HTML, CSS, and JavaScript.

## Project Overview
This project showcases a brand website for Malligai Advertising Agency with sections for:

- Home
- About
- Services
- Photography
- Contact

## Features
- Responsive landing page design
- Multi-language support (English and Tamil)
- Photography gallery section
- Contact form integration
- Service video section

## Local Preview
Open the project folder in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `malligai-advertising-agency-2-emailjs-ready.html` - main website file
- `photography/` - gallery images

## Deployment
This site is a static website and can be hosted on:

- GitHub Pages
- Netlify
- Vercel
- any static hosting service
